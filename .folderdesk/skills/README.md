# Foundational Local Skills

This course starts from the small public FolderDesk/FD Tiny Skill foundation.

| Skill | Purpose |
|---|---|
| `structure` | decide where material belongs without duplicate folder systems |
| `skill-builder` | turn proven repeated behaviour into a reusable Skill |
| `lessons` | promote meaningful learning into future behaviour |
| `auditor` | detect drift and unnecessary complexity |
| `document-intake` | preserve and route useful file/document inputs |
| `client-experience` | keep future client-facing work business-first |

Course progression will later have André build his own Skill rather than only use these examples.
