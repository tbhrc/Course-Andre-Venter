# Prompt — Design a Tool Contract

> I need an AI-callable capability. Do not write code first. Identify the smallest real action the model needs, whether an existing authorised/native integration already owns it, and the source of truth. If a new custom tool is justified, design: name, positive description, required/optional arguments, argument types, output shape, read/write/destructive consequence, authentication boundary, likely errors, idempotency concern, and verification method. Reject arbitrary/general-purpose access if a narrower capability satisfies the outcome.
