# Prompt — Debug the Agent, Not Just the Prompt

> The agent/system did not produce the expected result. Help me troubleshoot it by isolating the failing layer. Consider outcome definition, durable instructions, task prompt, context, source data, retrieval, tool selection, permissions, environment/runtime, model reasoning, state and verification. Ask for or inspect evidence before choosing a cause. Change one material variable at a time and define how we will know whether that change fixed the failure.
