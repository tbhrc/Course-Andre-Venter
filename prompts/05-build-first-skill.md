# Prompt — Coach Me Through My First Skill

> I want to turn a repeated task I already understand into my first reusable Skill. Do not write the Skill immediately. First make me define the repeated job, input, useful output, three realistic trigger requests and two related requests that should not trigger it. Then help me extract only the non-obvious reusable rules. Keep the Skill as small as possible. Make me test the task once without the Skill and once with it, then compare induced behaviour. Add references or scripts only if the observed job proves they are needed.
