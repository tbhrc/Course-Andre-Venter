# 30 / 60 / 90 Day Continuation Path

The course ends with independent building, not more passive study.

## Days 1–30 — Repeat the fundamentals

Build **two small single-agent projects** in different domains.

For each:

- root AGENTS.md;
- one real outcome;
- one source-of-truth map;
- Git history;
- one Skill only if repeated HOW earns it;
- one tool/API where useful;
- 5–10 representative eval cases;
- one deliberate failure drill.

Target:

> Become fast at building small, reliable agent loops.

Do not build multi-agent systems yet unless a project clearly proves the need.

## Days 31–60 — Operate a real workflow

Choose one project with recurring real use.

Track:

- actual tasks completed;
- failures;
- user corrections;
- latency;
- cost where material;
- tool reliability;
- regression cases.

Promote only material lessons into the correct owner.

At the end of 60 days, perform a KISSS review:

```text
DELETE
COLLAPSE
REUSE
DIRECT
ADD only if earned
```

Target:

> Learn from production-shaped evidence.

## Days 61–90 — Expand only proven constraints

Now consider one advanced improvement:

- richer state;
- stronger eval automation;
- MCP server;
- background/long-running work;
- multi-agent specialist split;
- deployment hardening;
- observability improvement.

Choose **one** because measured use justifies it.

Compare before/after:

- quality;
- speed;
- cost;
- reliability;
- complexity.

Target:

> Become an architect who adds complexity only when evidence earns it.

## Ongoing operating habit

For every future system:

```text
OUTCOME
→ smallest working architecture
→ real use
→ observed failure
→ targeted improvement
→ eval
→ reusable lesson
→ KISSS
```
