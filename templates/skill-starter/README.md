# Skill Starter Template

This is a **core logic template**, not a finished distributable ChatGPT package.

Start by copying `SKILL.md` into your working Skill folder.

Do not add `references/`, `scripts/` or `assets/` until the real task proves they are needed.

If you later package the Skill for a specific AI platform, follow that platform's current packaging/metadata requirements rather than assuming this course template is the complete distribution bundle.

For ChatGPT packaging, use current official Skill tooling/validation because platform metadata can evolve.
