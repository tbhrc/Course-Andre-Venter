# André Venter — Graduation Challenge

Use the canonical [GRADUATION.md](GRADUATION.md) criteria plus this personalized final challenge.

## Challenge

Choose a technical problem you understand well but **do not reuse your capstone implementation**.

Examples:

- maintenance evidence workflow for a different machine/process;
- audio/video project preflight;
- technical vendor handover;
- small operational software tool.

Without being given the architecture, build the smallest useful agentic system.

The learner profile may guide examples and pacing, but it must not become a crutch. The final challenge should require André to transfer the method to a problem that is different enough from his capstone to prove the underlying Agentic AI skill has generalized.

## André-specific proof

You must be able to explain, without AI assistance:

1. which information is live state vs historical memory;
2. why each component exists;
3. why one agent is or is not sufficient;
4. which part is semantic AI judgement;
5. which part should be deterministic;
6. what system/file owns authoritative state;
7. how you test the result;
8. how you diagnose a failure;
9. which action has the highest real consequence;
10. how the system returns to a known-good state;
11. what would have to change before real production use.

## Final standard

The goal is not to become a conventional programmer.

The goal is to become someone who can take a real technical or business problem and confidently:

```text
understand it
→ architecture it
→ build with AI
→ inspect the work
→ connect systems
→ debug failure
→ verify evidence
→ control risk
→ explain the whole system
```
