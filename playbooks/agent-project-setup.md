# Playbook — Set Up a New Agent Project

## 1. Define the real outcome

Write one sentence describing what useful result the project should produce.

## 2. Identify truth

List the sources the agent is allowed to rely on.

## 3. Create the smallest workspace

```text
README.md
AGENTS.md
work/
knowledge/
outputs/
```

Add machinery only when a real need appears.

## 4. Write the root instructions

Include:
- purpose;
- repository routes;
- stable operating rules;
- real boundaries;
- verification expectation;
- stop condition.

## 5. Add one representative task

Do not start with a giant backlog.

## 6. Run a clean-context test

Have a fresh agent enter from `AGENTS.md` and attempt the representative task.

## 7. Fix induced behaviour

If the agent loads the wrong material, creates duplicate structure, guesses missing facts or skips verification, correct the instruction/Skill that induced the failure.

## 8. Commit the proven foundation

Now the project has a durable baseline.
