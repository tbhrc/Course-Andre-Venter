# AGENTS.md — Starter Repository

## Purpose

This is a small teaching repository for practising supervised coding-agent work.

## Rules

- Preserve the public function name `summarize_tasks`.
- Preserve the JSON task shape: `title` string + `completed` boolean.
- Do not add third-party dependencies.
- Do not edit tests merely to make failures disappear.
- Keep the implementation small.
- Run the documented unit tests after changes.
- Show the diff before claiming completion.
