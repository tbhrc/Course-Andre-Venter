## Stable concepts to learn

The product interface may change. The supervision method is more durable:

```text
scope
→ provide project context
→ inspect before change
→ make one bounded change
→ review diff
→ run tests/checks
→ diagnose failure
→ correct or rollback
→ verify outcome
```
