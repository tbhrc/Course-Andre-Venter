# AI & Agentic AI Course — André Venter

**Personalized learner track:** [Canonical Course-Agentic-AI](https://github.com/tbhrc/Course-Agentic-AI) · [Relationship](CANONICAL-COURSE.md)

A practical, build-first learning repository for **André Venter**.

This course is designed for someone who is already technically capable across software, audio/video systems, industrial machinery, troubleshooting and maintenance, but is new to building with modern AI agents.

The objective is not to study AI from the outside. The objective is to learn how to **operate, control, build, test and improve useful AI systems**.

## Start here — give this repository to your AI

Copy this prompt into ChatGPT, Codex, Claude, or another capable coding/agent environment:

## The learning path

```text
1. AI mental models
2. Operating one agent well
3. Project instructions and AGENTS.md
4. Files, Markdown, Git and GitHub
5. Reusable Skills
6. Codex and agentic coding
7. Tools, APIs and MCP
8. State, memory, data and verification
9. Building reliable agents
10. Capstone: a useful real-world agent
```

## Course doctrine

**Learn by operating and building.**

Do not spend weeks memorising AI terminology before touching real systems. Each concept should quickly become an action, file, workflow, test or small build.

The progression is:

**instructions → context → files → Skills → Git → Codex → tools/APIs/MCP → reliable agents → orchestration later**

Multi-agent systems come after André can reliably operate and verify one agent.
